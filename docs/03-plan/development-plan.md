## 工程管理规则

1. **每周一** 更新本文件 WBS 勾选状态（`- [x]`），并在 CI 面板核对构建绿灯。
2. **里程碑验收** 需满足对应验收标准并输出报告，缺一不可进入下一 Phase。
3. 需求变更 → 先记 ADR，再更新 `01-requirements/requirements.md`。
4. 缺陷密度（每千行）> 阈值时触发质量门禁，暂停合入新功能。

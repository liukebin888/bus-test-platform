# 里程碑定义

## M1：硬件平台 + 吞吐/时间戳基准达标（W14）

**验收标准**
1. 8 通道板卡样机 3 台，原理图/PCB/BOM 冻结 v1.0。
2. FPGA 六个 IP（打戳/过滤/注入/采样/调度/PPS）RTL 仿真与上板验证通过。
3. 基准测试：聚合吞吐 ≥ 50k msg/s、时间戳 100ns、周期抖动 < 100µs。
4. USB HS 480Mbps 链路稳定，带宽余量 ≥ 2.3 倍。
5. PC 端对象模型 + HAL + 零拷贝管线可在无硬件（Null Device）下跑通。

**退出条件**：输出《M1 基准测试报告》，问题单 ≤ 3 个 P1。

## M2：仿真+诊断功能完整的 Beta 版（W28）

**验收标准**
1. RBS 确定性事件循环 1ms 基准时隙达标。
2. Python DSL + CAPL 兼容层：on_message/on_timer/output/setSignal 语义对齐。
3. 协议族：J1939 / CANopen / ISO-TP / CAN XL 模块可用。
4. 诊断栈：UDS 全服务 + ODX 导入 + Seed&Key + 刷写状态机通过冒烟测试。
5. 分析视图：Trace/Graphics/Statistics/State Tracker 可交互。
6. 测试闭环插装里程碑完成 W15-28 全部交付。

**退出条件**：内部 Beta 发布会，覆盖度 ≥ 70%。

## M3：对标 CANoe 的 v3.0 正式发布（W40）

**验收标准**
1. TFS 测试框架 + 一致性测试套件（CAN FD/LIN 子集）通过。
2. J2534/RP1210/SocketCAN 兼容层 + MF4 日志 + 离线分析可用。
3. 多设备级联同步 < 1µs；72h soak 内存零增长。
4. CE/FCC 认证通过；用户手册/API 文档/示例工程齐备。
5. 覆盖度收敛 88% → 92%（22 项差距矩阵）。

**退出条件**：正式发布版 + 验收报告 + CI 全链路绿灯。

## 发布门禁（Quality Gate）

- [ ] 全部 P0/P1 缺陷关闭，P2 遗留有明确计划
- [ ] 千级用例回归通过率 ≥ 99%
- [ ] 需求覆盖率 100%（REQ-xxx ↔ 用例 ↔ 代码双向可追溯）
- [ ] 文档齐备（用户手册/开发文档/API 文档/示例工程）
- [ ] 认证报告归档（CE/FCC/EMC）

# 工程文档索引

本目录承载工程开发所需的全部支撑文档。**技术方案的单一事实来源**为
`reference/汽车总线测试平台技术解决方案-集成版.html`（v3.0），本目录文档为其工程化落地视图。

| 目录 | 内容 | 维护者 |
|---|---|---|
| `01-requirements/` | 需求基线（REQ-xxx 编号，含验收标准） | 项目经理 / 系统工程师 |
| `02-architecture/` | 系统架构（三域全景、五层软件架构、线程模型） | 软件架构师 |
| `03-plan/` | 40 周开发计划 WBS + 里程碑定义 | 项目经理 |
| `04-standards/` | 编码规范 / Git 工作流 / 评审清单 | 全体工程师 |
| `05-adr/` | 架构决策记录（ADR） | 架构师 + 评审委员会 |
| `reference/` | 上游设计文档（集成版 v3.0 HTML） | 归档 |

## 文档约定

- 需求变更走 ADR + 需求基线双通道：先记决策（`05-adr/`），再更新基线（`01-requirements/`）。
- 代码注释使用英文（ASCII），工程文档使用中文。
- 任何与上游方案不一致处，以 `reference/` 集成版为准并在此登记偏差。

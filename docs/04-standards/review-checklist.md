# 代码评审清单

## 通用

- [ ] 命名/格式符合编码规范；无调试残留（printf/TODO 需说明）
- [ ] 无未处理错误路径；资源（内存/句柄/锁）正确释放
- [ ] 边界条件覆盖（空输入、满缓冲、超长、并发）
- [ ] 变更对应需求编号（REQ-xxx）或缺陷单
- [ ] 测试：新增/修改代码有对应单测，CI 全绿

## 嵌入式 / 固件

- [ ] ISR 内无阻塞/动态内存；标志与队列使用正确
- [ ] 外设初始化顺序正确；看门狗与错误恢复路径存在
- [ ] 位操作无歧义；寄存器访问封装一致
- [ ] 堆栈/内存预算复核（RTOS 任务栈、全局缓冲）

## FPGA RTL

- [ ] 无组合环路 / 无意外 latch；复位策略一致
- [ ] CDC 路径已标注并经同步器/异步 FIFO 处理
- [ ] 时序约束（XDC）覆盖所有时钟域；时序报告通过
- [ ] testbench 覆盖正常/异常路径，仿真结果附于 PR

## PC 软件

- [ ] 跨线程共享已文档化或加锁；无数据竞争
- [ ] 性能热点批处理（16ms 渲染批、批量解析 16 帧）
- [ ] 外部输入（文件/网络/脚本）已做健壮性校验
- [ ] 日志分级合理，无敏感信息泄露

## 测试工程

- [ ] 用例四段结构完整（用例头/前置条件/步骤/期望判定）
- [ ] 期望判定可自动判定（可断言化），非人工目检
- [ ] 用例与需求/缺陷可追溯
